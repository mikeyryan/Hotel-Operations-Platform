# Roadmap

This roadmap is outcome-based. Dates can be added once development velocity is known.

## Phase 0 — Development environment

- Run a clean Expo starter on a physical phone
- Confirm phone and computer connectivity
- Add formatting, linting, and environment-variable conventions
- Record the first setup instructions and blocker log

**Exit condition:** another developer can clone the repository and open the starter app using the written instructions.

## Phase 1 — Clickable product skeleton

- Navigation and role-based home screens
- Static request list and request details
- New-request form with sample data
- Basic design system and accessibility pass

**Exit condition:** users can walk through the intended workflow without a backend.

## Phase 2 — Working MVP

- Authentication and roles
- Database-backed requests
- Assignment and status changes
- Photo upload with secure access
- Activity history and filters

**Exit condition:** the full MVP acceptance scenario works for multiple test accounts.

## Phase 3 — Pilot readiness

- Notifications
- Error handling and monitoring
- Permission and privacy review
- Usability testing with representative hotel staff
- Backup, retention, and support procedures

**Exit condition:** a controlled pilot can be run with synthetic or approved data.

## Phase 4 — Insights

- Operational dashboard
- Trend and response-time reports
- AI-assisted categorization and summaries
- Manager review and feedback controls

**Exit condition:** insights are demonstrably accurate, useful, and reviewable.
