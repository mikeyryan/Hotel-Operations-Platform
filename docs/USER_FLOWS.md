# User Flows

## Submit a request

1. Staff member opens **New request**.
2. Selects or confirms the room/location.
3. Adds a short description and optional photo.
4. Selects a category or accepts a suggested category later.
5. Reviews and submits.
6. App confirms the request number and `Open` status.

## Assign and complete work

1. Manager opens the unassigned queue.
2. Reviews details, photo, location, and priority.
3. Assigns the request to a person or department.
4. Assignee receives and opens the task.
5. Assignee marks it `In progress`.
6. Assignee adds a completion note and marks it `Completed`.
7. Reporter and manager can see the completed state and history.

## Key screens

- Sign in
- Staff home / My requests
- New request
- Request details and history
- My assigned tasks
- Manager queue
- Assignment control
- Basic operations summary
- Profile and settings

## Empty and error states to design

- No assigned tasks
- No requests match the current filters
- Photo permission denied
- Camera unavailable
- Submission failed or connection lost
- Request already updated by another user
- User lacks permission for an action
