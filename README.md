# ENG
## Project Goal
The goal of this project is to create a simple, convenient, and efficient system for hotel staff to report service requests, document problem with photos, and communicate those requests to hotel management 
The platform will eventually incorporate AI to analyze operational data and identity patters, bottlenecks, workload trends, and other useful insights for hotel managers. 

## 👥Users
### 👨‍🔧 Hotel Staff
Staff members will be able to:
- Submit service requests
- Take photos directly inside the application
- Describe problems without necessary typing
- Select rooms or locations
- View assigned tasks
- Update task status
- Track their submitted requests
### 👨‍💼 Hotel Managers
Managers will be able to:
- View submitted requests
- Search and filter requests
- View attached photographs
- Assign requests to staff
- Monitor task completion
- Analyze department activity
- View operational trends
- Generate reports

 ### 🤖 AI System
 The AI system will eventually help managers by: 
 - Categorizing service requests
 - Recommending request priorities
 - Identifying recurring problems
 - Detecting operational patters
 - Summarizing hotel activity
 - Identifying potential operational bottlenecks
 - Providing manager-facing recommendations
