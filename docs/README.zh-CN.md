# 酒店运营管理平台

这是一个面向酒店员工和管理人员的移动端运营协作平台。员工可以快速提交带有照片、位置和文字说明的服务或维修需求；管理人员可以分配任务、查看进度，并在积累可靠数据后分析重复问题、响应时间和工作量趋势。

> 当前状态：项目规划与早期开发阶段。本项目暂不适用于真实酒店的生产运营。

## 产品愿景

让酒店团队能够清楚回答：现在有什么问题、由谁负责、进展如何、哪些问题经常重复，以及哪些环节正在形成运营瓶颈。

## 第一版（MVP）

第一版只验证一个完整流程：

1. 员工提交需求，并添加房间或位置、说明和照片。
2. 管理人员查看并分配需求。
3. 负责人将状态从“待处理”更新为“处理中”，最后更新为“已完成”。
4. 相关人员可以查看当前状态和操作记录。

AI 分类、优先级建议、高级报表和自动化功能将在基础流程稳定后再开发。
